What Does This Tool Do?

The Card Deck Generator is a browser-based design tool for creating custom playing cards for board games, trading card games, and tabletop prototypes. It provides a full card editor with live visual preview, letting you define each card's title, description, type, stats, and artwork. You can build entire decks of cards, style them with custom colors and borders, choose from standard card size presets, and export your creations as individual PNG images, printable grid-layout sheets for cutting, or JSON files for saving and sharing your deck data. Whether you are rapid-prototyping a new game idea or producing print-ready assets for a small-run production, this tool streamlines the entire card creation workflow without requiring any design software.

Features

Live Card Preview

See your card update in real time as you type titles, descriptions, stats, and adjust colors. The visual preview mirrors exactly what your exported card will look like, eliminating guesswork from the design process.

Multiple Size Presets

Choose from industry-standard card dimensions including Poker (2.5 x 3.5 inches), Tarot (2.75 x 4.75 inches), Mini (1.75 x 2.5 inches), or define your own custom size for unique card formats.

Custom Card Styling

Personalize every card with configurable border colors, background colors, and text colors. Create visually distinct card types by assigning different color schemes to different categories within your deck.

Deck Management

Build multi-card decks with an intuitive list panel. Add, duplicate, delete, and reorder cards freely. Click any card in the list to instantly load it into the editor for modifications.

Flexible Export Options

Download individual cards as high-resolution PNG images, generate a printable sheet with all cards arranged in a grid layout ready for cutting, or save your entire deck as a JSON file for backup and sharing.

JSON Import and Export

Save your deck progress as a JSON file and reload it later to continue editing. Share deck files with collaborators or use them as templates for creating new card sets from existing designs.

How to Use

  1. Add a New Card: Click the "Add Card" button in the Deck Cards panel on the left to create a new blank card. The card appears in the list and is automatically selected for editing.
  2. Fill in Card Details: Enter the card's title, description, type or category label, and optionally set up to three stat values with custom labels such as ATK, DEF, or HP. Upload an image if desired.
  3. Choose Card Size: Select a size preset from the options beneath the editor fields. Pick Poker, Tarot, or Mini for standard dimensions, or choose Custom to specify your own width and height in inches.
  4. Style the Card: Use the color pickers to set the card's border color, background color, and text color. The live preview updates immediately so you can fine-tune the look before exporting.
  5. Build Your Deck: Continue adding cards to build your full deck. Use the Duplicate button to create copies of existing cards for faster creation. Drag or use the reorder arrows to arrange cards in your preferred order.
  6. Export Your Work: Download the currently selected card as a PNG image, generate a printable sheet of the entire deck arranged in a grid, or export the deck data as JSON to save your progress and reload it later.

FAQ

What image formats can I upload for card artwork?

The card image field accepts any standard web image format including PNG, JPG, GIF, SVG, and WebP. For the best results, use images with an aspect ratio close to the card's image area dimensions. Transparent PNG files work well for icons and character art.

What resolution are the exported PNG cards?

Cards are rendered at 300 DPI based on the selected card size, which produces print-quality images. A standard Poker-sized card exports at approximately 750 x 1050 pixels, suitable for both digital use and physical printing.

How does the printable sheet export work?

The print sheet export arranges all cards in your deck onto pages in a grid layout, fitting as many cards as possible per page at their selected dimensions. The output is designed so you can print it on standard paper and cut along the card edges.

Can I save my deck and come back to it later?

Yes. Use the "Export Deck as JSON" button to download a JSON file containing all your card data, styling, and order. When you return, click "Import Deck from JSON" and select the saved file to restore your entire deck exactly as you left it.

Is there a limit to how many cards I can add to a deck?

There is no hard limit enforced by the tool. You can create as many cards as your browser memory allows. For very large decks with many high-resolution images, performance may vary depending on your device's available resources.

Can I use different sizes for different cards in the same deck?

The card size setting applies to the entire deck uniformly to ensure consistency for printing and layout. If you need cards of different sizes, you can create separate decks for each size and export them independently.
