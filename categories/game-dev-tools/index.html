Game Dev Tools

Utilities to speed up your game development workflow.

Free online tools built for game developers, tabletop designers, and creative worldbuilders. Slice sprite sheets, calculate dice probabilities, generate printable card decks, and create fantasy character names for every race — all instant, browser-based, and with no signup required. Whether you are prototyping a video game, running a D&D campaign, or writing a fantasy novel, these tools are ready to use right now.

Sprite Slicer

Upload a sprite sheet and slice it into individual frames by rows and columns. Drag lines to fine-tune uneven sprites.

Image Tiler

Tile images into patterns — single repeat, checkered, layered stacks, 4×4 border patterns, or random mix grids up to 10×10.

Dice Combination Sheet

Enter dice notation like 3d6 or 2d8+1 and get a full probability table, distribution chart, and stats for every possible outcome.

Card Deck Generator

Design and export printable cards for board games or TCG prototypes. Customize layout, colors, stats, and export as PNG or print sheets.

Fantasy Name Generator

Generate character names for D&D, games, and writing. Choose from 8 fantasy races with unique phoneme-based name construction.

Role Dealer

Secret role assigner for Mafia, Werewolf, and custom party games. One host creates a room — everyone joins on their phone.

Common Use Cases

  • Game prototyping — Slice sprite sheets and generate card decks for rapid board game or video game prototyping.
  • Tabletop RPG prep — Roll dice probability tables, generate NPC names, and build encounter resources for D&D, Pathfinder, and other systems.
  • Fantasy writing — Create authentic-sounding character names across eight fantasy races for novels, screenplays, and worldbuilding projects.
  • Game design analysis — Use the dice combination sheet to balance combat mechanics, loot tables, and random encounter probabilities.
  • Print-and-play production — Design and export printable card sheets for small-run board game productions, no design software needed.
