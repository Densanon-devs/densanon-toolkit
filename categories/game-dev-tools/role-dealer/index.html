How It Works

  • Host a game — Set up roles (Murderer, Detective, Doctor, or custom), adjust counts, and create a room.
  • Share the code — Everyone opens this page on their phone and joins with the 4-letter room code.
  • Deal roles — The host deals when ready. Each player taps their card to privately reveal their secret role.
  • Re-deal anytime — Shuffle and re-deal for a new round without anyone leaving the room.

Common Use Cases

  • Mafia / Werewolf — Classic party game role assignment without a physical moderator deck.
  • Murder mystery nights — Assign suspects, detectives, and the murderer for in-person mystery games.
  • Custom party games — Add any role you want with custom names and descriptions.
  • Game dev playtesting — Quickly assign roles or teams during tabletop or social deduction playtests.
