How to Resize Images in Batch

Upload any number of images (PNG, JPG, WebP, BMP, or GIF), choose a resize mode, set your target dimensions or percentage, and click Resize Images. Download all results as a single ZIP or save images individually. Everything runs client-side in your browser — no files are uploaded to any server.

Resize Modes Explained

  • Percentage — Scale all images by a factor (e.g., 50% halves both dimensions). Great for bulk downscaling.
  • Exact dimensions — Set a precise width and height. Use the aspect ratio lock to constrain proportions automatically.
  • Max width/height — Fit images within a bounding box, keeping aspect ratio intact. Ideal for web thumbnails.
  • Presets — One-click sizes for social media platforms, thumbnails, and HD resolutions.
