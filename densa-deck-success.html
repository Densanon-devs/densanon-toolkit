How to set up Densa Deck (first time)

This is a one-time setup that takes about 10 minutes. After that, the app launches instantly and runs fully offline.

  1. Download the ZIP using the button above. The file is about 26 MB.
  2. Using the installer? Double-click Densa-Deck-Setup-0.1.5.exe and follow the prompts — it creates Start Menu and Desktop shortcuts, then skip to step 5. Using the portable ZIP? Right-click Densa-Deck-0.1.5-windows.zip → Extract All... → pick a permanent location (Documents works well). Do not run the app from inside the ZIP preview — any data it saves will vanish when you close the window.
  3. Find densa-deck.exe. Open the extracted densa-deck\ folder. You'll see ~35 files; the one you want is densa-deck.exe (plain black-box icon labeled "densa-deck"). Ignore the _internal\ folder — those are dependencies, don't open anything inside it.
  4. Double-click densa-deck.exe. The app launches. A first-run walkthrough pops up — you can follow it or skip to step 5.
  5. Install the card database. Open the Settings tab → click Install card database. This downloads ~250 MB of Scryfall card data (5–10 minutes on a normal connection). You only do this once.
  6. Activate your Pro license. Still on the Settings tab, paste the key from above into Activate Pro license → click Activate. The tier badge in the top-right flips to Pro — Save, Goldfish, Gauntlet, and AI Coach are now unlocked.
  7. (Optional) Install the AI analyst model. If you want executive-summary narration + the AI Coach chat, click Download analyst model in Settings. Adds ~1.8 GB for the Qwen 2.5 3B model. Skip this if you just want the deck-analysis numbers.
  8. Start analyzing. Go to the Analyze tab, paste a decklist, click Analyze.

Save this key! It can be re-derived from your Stripe receipt if needed, but it's easier to bookmark this page or copy the key to a password manager now.

Disk space: plan for ~1.5 GB free on the drive you extract to (card database + optional AI model + room for version history). The app itself is only 25 MB; the data is where the space goes.

Two ways to install: v0.1.5 ships as both a one-click Windows installer (Start Menu + Desktop shortcuts, Add/Remove Programs entry) and a portable ZIP (no install, just extract and run). Your license key works with both — pick whichever you prefer.

⚠️ If Windows shows a security warning

Windows SmartScreen may show a blue "Microsoft Defender SmartScreen prevented an unrecognized app from starting" dialog when you run the installer. This happens because Densa Deck isn't yet signed with a paid code-signing certificate — we're adding one once sales volume supports it.

To continue: click More info at the top of the dialog, then Run anyway. The installer is safe; you can verify the file's SHA-256 hash against the one published on the GitHub release page.
